- state_demographics (state attributes, join to the state table on state_id): live_births, marriages, population, stat_year, state_id

RULES — every one of these is enforced by a validator before your statement runs; a statement that violates any of them is rejected, so follow them exactly:

TASK: Fetch the requested attribute values for the requested places and years from this agent's own tables. Return one row per place per year that exists here. OUTPUT COLUMNS: entity_name (the place name), year (the period column), then every requested attribute aliased by its own name, in the order given. Order the rows by entity_name, then year.

Return ONLY {"sql": "<the statement>"}.
